# 🎨 Unlimited Color

A simple JavaScript project that continuously changes the background color of a webpage every second.

Click **Start** to begin changing the background color and **Stop** to stop the effect.

## 🚀 Features

* 🎨 Generates random background colors
* ⏱️ Changes the color every second
* ▶️ Start button to begin the color-changing effect
* ⏹️ Stop button to stop the effect
* 💻 Simple and beginner-friendly JavaScript project

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Unlimited-Color/
│
├── index.html

└── unlimitedColors.js
```

## ⚙️ How It Works

The project uses JavaScript's `setInterval()` function to repeatedly generate a new color at a fixed interval.

### Start

When the **Start** button is clicked, the background color starts changing every second.

### Stop

When the **Stop** button is clicked, the interval is cleared and the background color stops changing.

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/ISaGix-16/Unlimited-Color.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Click **Start** and enjoy the changing colors! 🎨
